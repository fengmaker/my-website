# 作息与精力

学习安排只有能够长期执行才有用。我把每天的开始与收尾做得简单一些，减少临时决定下一步做什么的时间。

## 开始一天

1. 看一眼今天最重要的一件事，把它改写成可以完成的动作。
2. 准备资料和工作环境，先做一小段不需要额外准备的任务。
3. 如果状态不好，降低任务量，但保留“开始”这个动作。

## 结束一天

1. 记下今天完成的内容和仍然卡住的问题。
2. 写出明天的第一个具体动作，例如“补上这个 DP 的边界样例”。
3. 给工作与休息留出清楚的分界，避免睡前继续处理复杂任务。

## 每周回看

比起单独评价某一天，更值得看一周里哪些安排反复有效、哪些任务总被推迟。遇到反复推迟的任务，我会先检查它是否太大、起点是否不明确，再决定怎样调整。

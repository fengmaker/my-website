# 学习与复盘

我希望学习记录能回答两个问题：**今天真正弄懂了什么？下次遇到同类问题，我能否独立做出来？**

## 一个学习循环

1. **先定一个小目标。** 例如“说清 0-1 背包为什么要倒序遍历”，比“学动态规划”更容易验证。
2. **先自己尝试。** 写下状态、转移和边界；做不出来时也保留当时的判断。
3. **对照资料修正。** 找出差异是概念、推导、实现，还是没有看清题目条件。
4. **用自己的话输出。** 留下一个最小例子、一段可以运行的代码和一个容易出错的边界。
5. **隔一段时间再做。** 不看答案重做，才知道这次学习是否留下来了。

## 复盘时记录什么

| 项目 | 要回答的问题 |
| --- | --- |
| 目标 | 当时想解决什么问题？ |
| 原思路 | 我是怎样定义状态或建立模型的？ |
| 卡点 | 哪一步推不下去，或在哪个样例上出错？ |
| 修正 | 正确做法依赖什么条件？ |
| 验证 | 用了哪些边界样例确认结论？ |
| 下次 | 再遇到相似问题时，先检查什么？ |

对于算法题，我会优先留下**状态定义、转移、初始化、复杂度和反例**。对于运筹问题，我会额外写清**变量、约束、目标函数及模型适用范围**。

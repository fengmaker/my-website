## 我怎样检查一道题

1. 用一句话说清问题，标出输入规模、可选操作和答案是否允许为空。
2. 定义状态或维护量，说明它代表“前缀”“以当前位置结尾”还是“从当前位置出发”。
3. 推导转移，再单独处理初始化与边界。
4. 用最小样例、全负数、空边界或重复元素等情况验证代码。
5. 写下复杂度；如果使用 Python 列表插入、切片等操作，也计入成本。

部分代码沿用 LeetCode 的 `Solution`、`List` 和 `TreeNode` 等题目环境。阅读时应先确认适用条件；写成独立脚本时还需要补齐相应的类型或数据结构定义。

算法基础也会用于运筹问题，例如背包、最短路、搜索与路径定价。这里先把每种方法在原题里的条件讲清楚，再考虑它与运筹模型的联系。

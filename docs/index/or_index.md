## 代表项目

<div class="grid cards" markdown="1">

- **VRPTW Solver · 时间窗车辆路径**

    可行 ILS、限预算减车与 C++ 局部搜索。56 个 Solomon 实例、两档预算、四个求解器，共 448 条主实验记录。

    [查看实现、对照实验与路线图](../运筹优化/项目与实验复现/VRPTW-Solver.md)

- **GMRP-ALNS · 机器重分配**

    增量状态、ALNS 与受限 CP-SAT 修复。660 条归档观察，保留简单方法更优与超容差的短预算结果。

    [查看实现、真实结果与限制](../运筹优化/项目与实验复现/GMRP-ALNS.md)

</div>

项目结果来自固定版本的历史实测，数据、预算、指标基准与复现步骤见各项目页。[浏览完整作品集](../运筹优化/项目与实验复现/index.md)。

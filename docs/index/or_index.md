# 运筹优化：知识体系与学习地图

这部分按“理论 → 方法 → 问题 → 实现 → 项目”的主线组织，面向运筹优化算法的系统学习与工程实践。大部分既有内容参考[笑笑的站](https://smilingwayne.github.io/me/OROpt/)；我会随着学习加入自己的理解并持续修订。引用内容的来源与授权信息见[参考资料与许可](../运筹优化/资料库与面试/参考资料与许可.md)。

## 通用笔记应回答的问题

1. 解如何表示，哪些操作保证可行，哪些需要修复或罚函数？
2. 邻域或算子改变什么，目标增量怎样计算和核对？
3. 如何接受新解、维护搜索状态、决定停止？
4. 同等计算预算下是否优于基线，随机性如何记录？

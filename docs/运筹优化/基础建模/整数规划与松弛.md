# 整数规划与松弛

路径是否使用、仓库是否开设、客户分配给哪辆车，都需要离散决定。整数规划（IP）要求部分或全部变量取整数；混合整数规划（MIP）同时含整数和连续变量。最常见的离散变量是 $x_j\in\{0,1\}$，表示方案 $j$ 是否被选择。

## 先辨认三个集合模型

令 $a_{ij}=1$ 表示方案 $j$ 覆盖对象 $i$，$c_j$ 为其成本。对每个对象 $i$：

| 模型 | 核心约束 | 含义 |
| --- | --- | --- |
| 集合覆盖 | $\sum_j a_{ij}x_j\ge1$ | 至少被一个方案覆盖 |
| 集合打包 | $\sum_j a_{ij}x_j\le1$ | 至多被一个方案占用 |
| 集合划分 | $\sum_j a_{ij}x_j=1$ | 恰好被一个方案覆盖 |

选择车辆路径、使每位客户恰好由一条路径服务，就是集合划分。目标通常是 $\min\sum_j c_jx_j$。约束的方向由业务要求决定，不能因为某种写法求解快就随意替换。

## LP 松弛提供什么

把 $x_j\in\{0,1\}$ 暂时改为 $0\le x_j\le1$，得到 LP 松弛。对于最小化问题，松弛可行域更大，因此它的最优值是整数最优值的**下界**；一个实际可行的整数解给出**上界**。上下界相等时，最优性得到证明。

松弛解可能是分数，因此不能把它直接当作业务方案。例如三角形的最小顶点覆盖要求每条边至少有一个端点被选。令三个顶点的变量都等于 $1/2$，LP 成本为 $1.5$，但整数解至少需要两个顶点，成本为 $2$。这段差距就是该模型在这个实例上的整数间隙。

逐个四舍五入也不可靠：可能破坏覆盖约束或容量约束，即使可行也未必最优。常见精确求解路线是先求 LP 界，再通过[分支定界](../图与离散优化/分支定界.md)排除分数解；割平面则尝试收紧松弛可行域。

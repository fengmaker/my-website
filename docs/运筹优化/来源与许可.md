# 来源与许可

“原站”目录收录自 [SmilingWayne/me](https://github.com/SmilingWayne/me) 中的“运筹与优化”栏目。所用源码版本为 [`371cfb49f7f9b0c2ee1c25a69a81352deae3558b`](https://github.com/SmilingWayne/me/tree/371cfb49f7f9b0c2ee1c25a69a81352deae3558b)。页面保留原作者的行文口吻；每页开头都标出了原文链接和作者。为适配本站，仅调整了站内链接、导航与少数原目录的误链。

原站文档中的图片主要使用原作者提供的外部 CDN 地址，本站沿用这些引用，因此图片显示取决于对应外部服务。

# 来源与许可

“原站”目录收录自 [SmilingWayne/me](https://github.com/SmilingWayne/me) 中的“运筹与优化”栏目。所用源码版本为 [`371cfb49f7f9b0c2ee1c25a69a81352deae3558b`](https://github.com/SmilingWayne/me/tree/371cfb49f7f9b0c2ee1c25a69a81352deae3558b)。页面保留原作者的行文口吻；每页开头都标出了原文链接和作者。为适配本站，仅调整了站内链接、导航与少数原目录的误链。

原站文章中可访问的 174 张图片已保存到 `原站/images/`；文章中的 178 处图片引用已改为本地相对路径。其中 173 张来自 [SmilingWayne/picsrepo](https://github.com/SmilingWayne/picsrepo)，另 1 张来自 [博客园原图](https://img2018.cnblogs.com/blog/1903168/201912/1903168-20191220004845529-3040599.jpg)。原文另有一条已注释、不会显示的外部图片链接，其源站已无法提供文件，归档时移除了这条注释。图片来源与下述文档仓库的许可分别列明。

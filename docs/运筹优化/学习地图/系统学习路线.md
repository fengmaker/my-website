# 系统学习路线

按“理论 → 方法 → 问题 → 实现 → 实验”的顺序推进。每一步都用一个小例子检验理解，再进入下一步；已有笔记与拟开展的实验分别列出。

| 步骤 | 阅读入口 | 自检或练习 |
| --- | --- | --- |
| 1 · 连续模型与对偶 | [线性规划与对偶](../基础建模/线性规划与对偶.md)、[单纯形法数值例子](../基础建模/单纯形法从数值例子理解基与检验数.md) | 手算一个小 LP，核对原始解、对偶解与检验数。 |
| 2 · 离散决定与松弛 | [整数规划与松弛](../基础建模/整数规划与松弛.md)、[0-1 变量建模](../基础建模/0-1变量建模.md) | 用一个反例说明 LP 解为何不能直接四舍五入。 |
| 3 · 搜索与最优性证明 | [最短路与网络流](../图与离散优化/最短路与网络流.md)、[分支定界](../图与离散优化/分支定界.md)、[割平面](../离散优化/Ch_07.md) | 分清可行解、下界、上界与停止条件。 |
| 4 · 问题的递进 | [TSP](../路径规划/TSP/总笔记.md) → [CVRP](../路径规划/CVRP/总笔记.md) → [VRPTW](../路径规划/VRPTW/总笔记.md) | 分别解释连通性、容量与时间窗如何改变可行域。 |
| 5 · 分解与定价 | [列生成与 DW 分解](../求解方法/列生成与DW分解.md) → [VRPTW DW 分解](../路径规划/VRPTW/dw分解.md) → [分支定价与标签算法](../求解算法/ExactVRP.md) | 追踪 RMP、对偶价格、约化成本和定价终止的含义。 |
| 6 · 快速构造与改进 | [启发式与元启发式索引](../求解算法体系/启发式与元启发式.md) | 在同一个可行解上观察邻域、接受准则和可行性检查。 |
| 7 · 实现与实验 | [工程实现索引](../求解器与工程实现/index.md)、[VRPTW 开发方案](../路径规划/VRPTW/研究方案.md) | 按[实验规范](../求解器与工程实现/实验规范.md)记录环境、数据和结果。此处是练习安排，尚不代表已完成实验。 |

## 按当前任务选入口

- 复习基础或准备面试：先读[基础理论与建模](../基础理论与建模/index.md)，再用[面试资料](../资料库与面试/index.md)定位薄弱点。
- 已确定研究问题：从[问题—算法索引](./问题算法索引.md)找到问题页，再回查算法原理。
- 准备写求解器：先确定问题假设、目标和可行性校验，再实现基线，最后增加算法算子；用[专题与实验记录模板](../项目与实验复现/专题与实验记录模板.md)记录选择依据。

TSP、CVRP 笔记中的“第一阶段”至“第四阶段”是本站阅读顺序；导航用实际模型与算法命名，便于按关键词检索。

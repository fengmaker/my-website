# 路径规划／运筹优化算法岗面试题库（130 题）

这是一套按真实面试对话重排的练习题，**不是出题频率统计，也不是某家公司的原题清单**。业务与项目题用来核实你是否做过完整问题：是否能澄清需求、建模、选法、验证和复盘。理论与算法题检验你能否解释原理、适用条件与正确性边界。面试官通常会沿你简历和项目中的方法继续追问，深层专题只需按投递岗位及真实经历准备。

准备顺序：先练两类题中的“常规主问”和“基础与常用原理”；“结合项目再追问”以真实项目记录作答；“专项技术追问”适合简历写了相应方法或投递求解器研发岗位时练习。**考点**说明面试官想核实的能力，不是标准答案。

逐题参考回答见[带题干的参考答案](./路径规划算法岗面试题库_参考答案.md)。

## 一、业务与项目题

### 常规主问

1. **[项目]** 用两分钟讲清你做的路径规划项目：业务目标、输入规模、约束、算法、结果和你本人负责的部分。
   - **考点：** 能否用真实数据说清个人贡献与项目结果
2. **[业务建模]** 面对一个末端配送需求，你会先向业务方确认哪些规则，再决定它是 TSP、CVRP、VRPTW 还是更复杂的变种？
   - **考点：** 能否先澄清业务规则再选择路径问题类型
3. **[目标函数]** “先最少车辆、再最短距离”与“距离加车辆固定成本”有何区别？怎样保证代码中的目标与业务优先级一致？
   - **考点：** 能否把目标优先级准确落到模型和代码
4. **[时间窗]** 给定一条路线，如何逐点计算到达、等待、开始服务和返回仓库的时间，并判断硬时间窗可行性？
   - **考点：** 能否正确递推到达、等待、服务和回仓时间
5. **[数据语义]** 距离矩阵和行驶时间矩阵为何要分开？服务时间、等待时间和车辆工作时长各进入哪些约束？
   - **考点：** 能否分清距离、行驶时间和司机工作时长
6. **[可行性]** 在调用求解器前，你会做哪些快速不可行性检查？这些检查为什么通常只是必要条件？
   - **考点：** 能否用必要条件提前发现明显不可行输入
7. **[工程]** 如何写一个独立于求解器的解验证器，检查漏访、重复访问、超载、迟到、车辆数和回仓库？
   - **考点：** 能否独立校验路线的全部业务硬约束
8. **[结果解释]** 什么是可行解上界、松弛下界和 MIP Gap？何时可以说“找到最优解”？
   - **考点：** 能否解释上界、下界与最优性证明
9. **[方法选择]** 对 30、300、3000 个客户且分别要求证明最优或限时给出可行解的任务，你如何选择精确算法、启发式或混合方案？
   - **考点：** 能否依据规模、时限和证明要求选法
10. **[项目实验]** 你的项目改善了什么指标？实例、时间预算、随机种子、基线和硬件是否一致？如何避免夸大改进？
   - **考点：** 能否用公平基线和一致预算证明改进
11. **[求解器日志]** 给你一段 MIP 日志，如何区分“迟迟找不到可行解”和“已有好解但下界不涨”？各自优先检查什么？
   - **考点：** 能否从 MIP 日志定位首解或下界瓶颈
12. **[工具选择]** Gurobi MIP、OR-Tools Routing、自己写 ALNS 各适合什么任务？如何比较“找可行解”和“证明最优”的能力？
   - **考点：** 能否按照证明需求和规模选择工具
13. **[现场场景]** 给 100 个订单、20 辆车、配送时间窗和司机下班时间，你会如何定义目标、变量、硬约束、软约束及最初可运行的基线？
   - **考点：** 能否在新场景中提出可运行的目标与约束基线
14. **[手写代码]** 写一个函数接收客户序列和实例数据，返回该路线的成本、完整时间表及第一个不可行原因；时间复杂度是多少？
   - **考点：** 能否写出可靠的路线评价与失败原因定位器
15. **[故障排查]** 算法返回“无解”时，你如何区分输入数据错误、模型写错、确实不可行和求解超时？
   - **考点：** 能否区分数据、模型与求解时限造成的无解
16. **[业务沟通]** 如果算法把总距离降低了 8%，却让一部分客户更晚收到货，你会怎样解释并重新定义评价指标？
   - **考点：** 能否识别距离改善与客户体验的冲突
17. **[时间窗语义]** 时间窗限制的是到达时刻还是开始服务时刻？若在最晚时刻到达但服务跨窗，算不算可行？
   - **考点：** 能否确认时间窗约束的业务语义
18. **[取送货]** 若订单有取货点和送货点，怎样加入先取后送、同车服务和沿路载重变化？
   - **考点：** 能否保证取送先后、同车和动态载重
19. **[软时间窗]** 客户允许迟到并支付罚金时，模型与 ALNS 评价函数如何改？怎样避免把软约束误当硬约束？
   - **考点：** 能否区分硬时间窗与迟到罚金
20. **[不可行性诊断]** MIP 模型不可行时，IIS、冲突分析、逐层放松约束各能帮助你发现什么？
   - **考点：** 能否用冲突信息定位当前模型的矛盾
21. **[求解状态]** `OPTIMAL`、`TIME_LIMIT`、`INFEASIBLE`、`INF_OR_UNBD` 等状态下，怎样决定是否可以读取并交付一个路线解？
   - **考点：** 能否按状态与解数量安全交付路线
22. **[数值稳定]** Big-M 过大、浮点误差、距离舍入和容差设置可能怎样制造“模型可行但业务不可行”的结果？
   - **考点：** 能否识别数值容差和舍入引起的业务违约
23. **[Gap 计算]** 求解器报告的相对 Gap 与业务希望看到的“相对最好已知解改进率”有何区别？
   - **考点：** 能否区分证明差距与基准改进率
24. **[动态订单]** 新订单在车辆已出发后到达，你会怎样做局部插入或滚动重优化，并保留已承诺的服务？
   - **考点：** 能否在滚动重算中保留已承诺服务
25. **[不确定性]** 行驶时间不稳定时，你会选安全裕度、鲁棒优化、情景优化还是仿真评估？选择依据是什么？
   - **考点：** 能否按风险要求选择不确定性处理方式
26. **[成本校准]** 业务提供油费、人工、违约金和车辆固定成本，你怎样把它们转换成一致单位且可解释的目标？
   - **考点：** 能否统一成本单位并防止重复计费
27. **[线上系统]** 每天批量重算与实时滚动规划的延迟、稳定性和可解释性要求有何不同？
   - **考点：** 能否权衡批量与实时规划的系统要求
28. **[数据质量]** 订单缺坐标、时间窗颠倒、需求为负、重复 ID 时，数据管线应怎样拒绝或修复输入？
   - **考点：** 能否定义输入门禁及可解释修复规则
29. **[测试]** 除了标准算例，你会设计哪些极小反例验证时间窗等待、单客户路线、零需求、紧容量和重复访问？
   - **考点：** 能否用极小反例覆盖关键可行性边界
30. **[模型审查]** 给你一份陌生 VRPTW 数学模型，如何检查仓库起终点、客户恰好服务一次、Big-M 激活方向和时间循环漏洞？
   - **考点：** 能否系统审查覆盖、连通和时间传递约束
31. **[临场建模]** 一项新业务同时有预约时间、司机技能、订单优先级和部分可拒订单，你会先给出什么最小可运行模型，再逐步加哪些限制？
   - **考点：** 能否先搭建正确的最小业务模型
32. **[缺失参数]** 业务拿不出准确服务时长或违约成本时，你会怎样估计、做敏感性分析并向业务说明决策风险？
   - **考点：** 能否用敏感性分析处理缺失业务参数
33. **[跨团队沟通]** 运营希望更少车辆，客服希望更少迟到，算法算出两者不能兼得时，你如何给出可选择的权衡方案？
   - **考点：** 能否向不同业务方展示可选权衡
34. **[复盘]** 一个上线试点没达到离线算例效果，你会怎样从数据、目标、求解时间、系统接入和实际执行逐层复盘？
   - **考点：** 能否对齐离线、线上和实际执行逐层复盘

### 结合项目再追问

35. **[项目追问]** 你为什么在 VRPTW 项目里选择 ALNS？比较过什么基线，哪些实际约束或计算预算影响了这个选择？
   - **考点：** 能否用项目证据说明 ALNS 的选型理由
36. **[项目架构]** 你的 `ProblemData`、`Route`、`Solution` 和搜索器分别负责什么？哪些状态必须在每次移动后更新？
   - **考点：** 能否说明数据、路线状态和搜索组件的职责
37. **[算例]** 你如何读取和核对 Solomon C101 / C102 文件中的仓库、客户、需求、时间窗、服务时长及车辆容量？
   - **考点：** 能否正确读取算例字段并核对单位与索引
38. **[搜索诊断]** ALNS 长时间没有改进时，你会区分“破坏力度不够”“修复过于贪婪”“接受率过低”还是“初始解太差”？
   - **考点：** 能否用日志定位 ALNS 停滞原因
39. **[增量评估]** 插入客户 $u$ 到 $(i,j)$ 之间时，距离增量为何易于 $O(1)$ 计算，而时间窗可行性可能影响整条后缀？
   - **考点：** 能否区分距离增量与时间窗后缀传播
40. **[时间缓存]** 前向最早服务时间和后向可用 slack 能怎样加快插入评估？哪些边界条件会使所谓 $O(1)$ 检查不正确？
   - **考点：** 能否正确使用时间缓存和 slack 的边界条件
41. **[性能]** 纯 Python VRPTW 搜索器的常见热点在哪里？你会先 profile 哪些函数，再决定改数据结构或引入编译组件？
   - **考点：** 能否通过 profile 定位真实运行热点
42. **[数据结构]** 距离矩阵、路线序列、访问集合分别适合怎样存储？何时使用列表、NumPy 数组或位集？
   - **考点：** 能否按访问模式和规模选择数据结构
43. **[动态行驶时间]** 若高峰时段行驶时间依出发时刻变化，原来的静态时间递推、标签支配和预处理要怎样改？
   - **考点：** 能否识别时变行驶时间对递推和支配的影响
44. **[异构车队]** 车辆容量、固定成本和行驶成本不同，主问题和定价如何表示“路线由哪类车执行”？
   - **考点：** 能否让车型差异进入路线变量与成本
45. **[多仓库]** 多个仓库时，路线生成、客户覆盖及车队限制如何变化？
   - **考点：** 能否正确处理多仓库覆盖和车队限制
46. **[规模分析]** 为什么时间窗收紧可能同时减少可行路线、却也使可行初始解更难找到？
   - **考点：** 能否解释紧时间窗对搜索的双重影响
47. **[求解器]** 初始启发式路线怎样作为 MIP start？它可能改善什么，又不能保证改善什么？
   - **考点：** 能否说明 MIP 启动路线的收益与局限
48. **[性能定位]** 求解时间主要耗在根 LP、定价、分离、分支树还是 Python 回调时，你分别会采取什么措施？
   - **考点：** 能否按求解阶段和代码热点制定改进措施

   - **考点：** 能否用一致口径与多次实验公平对比
50. **[算例对比]** 面对 C101 与 C102 或同系列不同编号实例，你会先比较哪些数据分布，再解释算法表现差异？
   - **考点：** 能否先比较实例数据再解释性能差异
51. **[基准一致性]** Solomon 距离和时间的计算、舍入、车辆数优先级若与论文不同，为何直接比较目标值可能失真？
   - **考点：** 能否按一致基准复算车辆数与距离
52. **[优先顺序]** 某些客户必须先于另一些客户服务时，紧致模型、标签状态和 ALNS 修复各需改什么？
   - **考点：** 能否在模型与搜索中正确加入先后规则
53. **[司机规则]** 加入司机休息、最长连续驾驶时间和班次限制后，标签资源与路线验证器如何扩展？
   - **考点：** 能否把司机休息与班次加入资源和验证
54. **[仿真]** 静态最优路线在真实运营中表现差，如何用仿真区分需求预测、ETA、路线模型和执行偏差的贡献？
   - **考点：** 能否区分预测、优化和执行误差来源
55. **[预测 + 优化]** ETA 模型的预测误差怎样传入时间窗可行性判断？只用平均预测值可能有什么后果？

57. **[增量更新]** 一条路线临时取消或交通时间更新后，哪些数据结构和中间结果可以复用，哪些必须重算？
   - **考点：** 能否管理缓存失效并复用可靠中间结果
58. **[SQL]** 订单表与客户位置表连接后出现重复订单，你会怎样用 SQL 定位一对多连接并验证去重规则？
   - **考点：** 能否识别一对多连接与可复现去重
59. **[Python 数据处理]** 用 pandas 从订单明细生成客户、需求、时间窗及距离矩阵时，如何检查缺失、单位和索引错位？
   - **考点：** 能否核对缺失值、单位和节点索引

## 二、理论与算法题

### 基础与常用原理

60. **[问题定义]** TSP、CVRP、VRPTW 各增加了哪些决策和约束？一个问题何时能退化为另一个？
   - **考点：** 能否根据车数、容量和时间窗识别问题结构
61. **[现场建模]** 从零建立标准 CVRP 的整数规划模型：定义变量、目标、客户度数、仓库度数和容量约束。
   - **考点：** 能否完整定义变量、目标和核心可行性约束
62. **[ALNS]** 从初始解到终止，完整讲述 ALNS 的破坏、修复、接受、算子选择和最佳解保存流程。
   - **考点：** 能否完整解释 ALNS 搜索与最佳可行解保存
63. **[ALNS 算子]** 随机、最差和 Shaw 相关性移除分别在什么情况下有用？贪婪与 regret 插入分别解决什么问题？
   - **考点：** 能否解释破坏与修复算子的作用和适用情境
64. **[修复算法]** 手推 regret-2 插入：怎样计算最佳与次佳插入代价，如何处理某客户没有可行插入位置？
   - **考点：** 能否手算插入后悔值并处理无可行位置
65. **[TSP 建模]** 只有每点度数为 2，为什么求出的可能不是一条完整巡回？举一个子回路例子。
   - **考点：** 能否用反例识别度数约束留下的子回路
66. **[DFJ]** 写出无向 TSP 的子回路消除约束，并说明内部边形式与割集形式为什么等价。
   - **考点：** 能否解释 SEC 的两种等价写法
67. **[MTZ]** MTZ 次序变量怎样消除子回路？为什么 Big-M 可能导致 LP 松弛较弱？
   - **考点：** 能否解释 MTZ 次序和 Big-M 松弛弱点
68. **[数值建模]** 对 VRPTW 时间传递约束，如何给每条弧推导尽量紧的 $M_{ij}$，并删除根本不可能使用的弧？
   - **考点：** 能否从时间窗推导逐弧 Big-M 并安全删弧
69. **[回调]** TSP 的 lazy constraint 与 user cut 各在何时加入、解决什么问题？若只做整数子回路分离会怎样？
   - **考点：** 能否区分整数解分离与分数解强化
70. **[手写代码]** 实现 Dijkstra 最短路并说明它的适用条件；为什么不能直接用于带负检验数弧的 ESPPRC？
   - **考点：** 能否说明最短路算法的适用条件
71. **[手写代码]** 网格中只能向右或向下，求左上到右下路径数；若部分格子禁止经过，状态转移如何变化？
   - **考点：** 能否写出网格路径计数的状态与转移
72. **[整数规划]** 分支定界如何利用上下界剪枝？初始可行解、强下界和分支变量选择各怎样影响搜索？
   - **考点：** 能否用有效界解释分支定界的剪枝
73. **[构造法]** 推导 Clarke–Wright 节约值；合并路线时为什么必须检查端点、容量和车数？
   - **考点：** 能否推导节约值并安全合并路线
74. **[局部搜索]** 对称 TSP 的 2-opt 如何改变路线？怎样用四条边计算距离增量，什么时候还必须重查时间窗？
   - **考点：** 能否计算 2-opt 增量并复核资源约束
75. **[VRP 算子]** Relocate、Swap、Or-opt、2-opt* 分别改变什么结构？跨路线移动后哪些缓存会失效？
   - **考点：** 能否识别跨路线移动与缓存失效范围
76. **[元启发式]** 禁忌搜索、模拟退火、ALNS 的“接受坏解 / 跳出局部最优”机制有何区别？
   - **考点：** 能否比较不同元启发式跳出局部最优的机制

# 运筹优化算法工程师面试题库（80 题）

这套题面向通用运筹优化算法工程师岗位，按建模与方法选择、精确算法、启发式与元启发式、求解器与工程落地四部分整理。它们是练习题，不是特定公司的原题。路径规划、VRP 与分支定价的领域题另见[路径规划算法岗题库](./路径规划算法岗面试题库.md)。

每道题的完整题干、参考回答和追问要点见[逐题参考答案](./运筹优化算法岗面试题库_参考答案.md)。建议先练 1–16 题的建模与界，再练 17–40 题的精确算法；41–60 题适合口述搜索流程，61–80 题结合实际求解器日志和项目经历准备。

## 一、建模与方法选择（1–16）

1. 优化问题的“求解方法”“求解算法”“求解器”分别指什么？举一个排班例子说明三者关系。
2. 精确算法、启发式算法、元启发式算法的差别是什么？“精确”是否意味着很快？
3. 给定问题规模、时限和质量要求，你如何在专用算法、MIP、CP-SAT、分解与启发式之间选择？
4. 接到一个“降低排班成本且满足服务水平”的需求，你会按什么顺序形成可求解模型？
5. 模型目标值降低了，但业务指标变差，可能是什么原因？如何处理？
6. 线性规划、混合整数规划、约束规划和动态规划各适合什么结构？
7. 最小化问题中可行解、松弛解分别提供什么界？相对 Gap 如何理解？
8. 两个整数模型可行整数解相同，为什么求解速度可能差很多？
9. 如何推导尽可能紧且有效的 Big-M？M 过大和过小各有什么风险？
10. “若开机则满足最小产量”如何建模？指示约束是否总比手写 Big-M 快？
11. 完全相同的机器或车辆为什么会使 MIP 难解？怎样安全破除对称性？
12. 求解器返回不可行、无界、时间到且无可行解，分别意味着什么？
13. 字典序目标和加权和目标有什么区别？怎样实现“先满足缺岗最少，再控制成本”？
14. 输入需求和成本有误差时，你如何判断方案是否稳健？
15. 在调用求解器前，你会做哪些数据和逻辑预检？
16. 比较 MIP、启发式和 CP-SAT 时，如何设计公平的实验？

## 二、精确算法与分解（17–40）

17. 单纯形法在做什么？为什么一个最优 LP 解还不能直接当整数问题答案？
18. 原始单纯形、对偶单纯形和内点法的起点与适用情境有什么区别？
19. LP 的对偶价格和列生成检验数如何解释？为什么符号容易写错？
20. 为什么某些看似整数的网络流或指派问题不必直接交给通用 MIP？
21. 用动态规划求最优解时，怎样判断状态定义充分且没有记录冗余信息？
22. 0-1 背包的动态规划为什么是伪多项式算法？容量很大时怎么办？
23. 用最小化 MIP 解释分支定界的节点处理和三种常见剪枝。
24. 深度优先、最佳界优先和强分支各在优化什么？
25. 求解器预处理通常做什么？为什么不能随意关掉或认为它不会影响调试？
26. 有效不等式和割平面是什么关系？一个“很紧”的约束可能为何无效？
27. Gomory 割和混合整数舍入（MIR）割的共同目的是什么？面试中要避免怎样的过度表述？
28. Lazy constraint 与 user cut 在语义上有什么区别？什么时候加错会影响正确性？
29. 分支切割相对纯分支定界增加了什么？割应只在根节点加吗？
30. 为什么把难处理的约束移入目标后可以得到下界？乘子如何选择？
31. 拉格朗日对偶的次梯度是什么？步长过大或过小会怎样？
32. Dantzig–Wolfe 分解为什么会把原变量改写成“列的组合”？
33. 列生成每轮做什么？找不到负检验数列时能证明什么？
34. 列生成后期为何常出现大量轮次却几乎不改善目标？如何处理？
35. 列生成得到了很好的 LP 下界，为什么不能直接把分数列解四舍五入？
36. Benders 分解怎样在“难离散决策”和“给定决策后的连续子问题”之间分工？
37. Benders 子问题不可行时，为什么不能简单把这次主问题解判为原问题不可行？
38. 一个模型同时有指数多的约束和指数多的变量时，你如何理解行生成与列生成？
39. 为什么只在根节点列生成后对受限主问题做普通分支，通常不能证明原整数模型最优？
40. 你实现一个自定义精确算法时，怎样向面试官证明它“精确”？

## 三、启发式与元启发式（41–60）

41. 构造型启发式、局部改进和元启发式各负责什么？怎样组织一个完整流程？
42. 如何判断一个贪心规则有最优性保证，还是仅是一条启发式？
43. 初始可行解对局部搜索和精确求解分别有什么价值？
44. 设计一个局部搜索邻域时，你会考虑哪些因素？
45. 为什么增量评估常比更换一个元启发式框架更能改善运行时间？怎样防止缓存错误？
46. 搜索过程中允许暂时违反约束有什么好处？最终如何保证输出可行？
47. 大邻域搜索为什么常采用“破坏—修复”？破坏比例如何影响搜索？
48. 禁忌搜索怎样避免在两个解之间反复来回？禁忌期限和特赦规则如何设置？
49. 模拟退火如何接受坏解？温度应该怎样初始化和冷却？
50. 遗传算法的编码、交叉和变异为什么必须结合问题结构？
51. 自适应大邻域搜索（ALNS）的算子权重怎样更新？为什么不能只用当前最优算子？
52. 变邻域搜索（VNS）为什么按多个邻域逐层尝试？
53. GRASP 的随机贪婪构造和后续局部搜索各起什么作用？
54. 迭代局部搜索（ILS）与简单随机重启有什么不同？
55. 种群或解池为何要维护多样性？你会怎样衡量两个方案有多不同？
56. 模拟退火温度、禁忌期限或 ALNS 破坏比例怎样调，才不容易过拟合算例？
57. 搜索停滞时，你如何区分应强化当前区域还是转向多样化？
58. 怎样把 MIP 求解器嵌入 LNS，而不是让它从零求整个问题？
59. 元启发式实验中固定随机种子是否足以保证完全复现？
60. 启发式找到成本 100 的可行解，怎样评价它离最优有多远？

## 四、求解器、诊断与落地（61–80）

61. Gurobi、OR-Tools CP-SAT、专用网络算法和自写启发式如何分工？
62. 一个带机器互斥、工序先后和最小完工时间的排程问题，为什么值得试 CP-SAT？
63. 读 MIP 日志时，你先看哪几个数来判断“找好解难”还是“证明难”？
64. 一个 MIP 两小时没有找到可行解，你按什么顺序排查？
65. 已有不错的可行解，但 MIP Gap 长期不降，优先做哪些检查？
66. 给求解器一个 MIP start 能保证什么？为什么提供的启动解可能被拒绝？
67. 调求解器参数时，为什么不建议一上来就把所有 cut 和 heuristic 开到最强？
68. TimeLimit、Gap、节点上限、找到首解就停，各适合什么业务要求？
69. OPTIMAL、FEASIBLE、INFEASIBLE、UNKNOWN 或 TIME_LIMIT 应如何映射到业务输出？
70. 模型确实不可行时，IIS 与 feasibility relaxation 分别帮你做什么？
71. 为什么目标系数和约束系数跨很多数量级会带来数值问题？如何处理？
72. 求解器返回二元变量 0.999999，算不算 1？交付方案怎样保证业务可行？
73. LP 基 warm start 与 MIP start 有何不同？模型小幅变化后哪个可能更有用？
74. 求解器 callback 可以做什么？实现 lazy constraint 或注入启发式解时有哪些风险？
75. 为什么增加求解器线程数未必线性提速？怎样做可复现的性能比较？
76. 用 Pyomo、JuMP 或 OR-Tools 建模后，为什么仍要说明实际调用的后端？
77. 为什么已有求解器可行性检查，还要自己写业务解验证器？
78. 新方法在公开实例上快了 20%，你还需要核对什么才能对外宣称改进？
79. 给 20 台机器、200 道工序、工序先后、换型时间和交期，如何先搭一个可运行基线？
80. 离线算例表现很好，上线后却经常超时或违反实际规则，你会怎样复盘？

## 使用建议

先独立回答，再对照答案补充公式、适用条件和反例。遇到项目题，用自己的真实实例规模、求解时间、可行性验证、上下界及失败案例替换通用表述。求解器功能和状态以所用版本的官方文档为准。

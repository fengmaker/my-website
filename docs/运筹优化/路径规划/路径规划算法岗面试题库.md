# 路径规划／运筹优化算法岗面试题库（130 题）

**适用岗位：** 配送路径规划、运筹优化算法工程师、物流优化 / VRP 求解器开发。题目依据 [TSP 总笔记](./TSP/总笔记.md)、[CVRP 总笔记](./CVRP/总笔记.md)、[VRPTW 总笔记](./VRPTW/总笔记.md)，结合公开面经与岗位要求重新编排；**它们是预测性练习题，不是某家公司的原题汇编**。

**排序方法：** 全局编号越小，越值得先准备。优先级是对公开材料与该岗位知识结构的综合判断，不代表统计出的真实出题概率。P0 要能口述并现场推导 / 编码，P1 要能说明原理和实现边界，P2 用于深挖与岗位拓展。每题后的方括号是考察方向。

逐题解析见[参考答案与高分标准](./路径规划算法岗面试题库_参考答案.md)。

## P0：最优先（1–40）

1. **[项目]** 用两分钟讲清你做的路径规划项目：业务目标、输入规模、约束、算法、结果和你本人负责的部分。
2. **[业务建模]** 面对一个末端配送需求，你会先向业务方确认哪些规则，再决定它是 TSP、CVRP、VRPTW 还是更复杂的变种？
3. **[目标函数]** “先最少车辆、再最短距离”与“距离加车辆固定成本”有何区别？怎样保证代码中的目标与业务优先级一致？
4. **[问题定义]** TSP、CVRP、VRPTW 各增加了哪些决策和约束？一个问题何时能退化为另一个？
5. **[现场建模]** 从零建立标准 CVRP 的整数规划模型：定义变量、目标、客户度数、仓库度数和容量约束。
6. **[时间窗]** 给定一条路线，如何逐点计算到达、等待、开始服务和返回仓库的时间，并判断硬时间窗可行性？
7. **[数据语义]** 距离矩阵和行驶时间矩阵为何要分开？服务时间、等待时间和车辆工作时长各进入哪些约束？
8. **[可行性]** 在调用求解器前，你会做哪些快速不可行性检查？这些检查为什么通常只是必要条件？
9. **[工程]** 如何写一个独立于求解器的解验证器，检查漏访、重复访问、超载、迟到、车辆数和回仓库？
10. **[结果解释]** 什么是可行解上界、松弛下界和 MIP Gap？何时可以说“找到最优解”？
11. **[方法选择]** 对 30、300、3000 个客户且分别要求证明最优或限时给出可行解的任务，你如何选择精确算法、启发式或混合方案？
12. **[项目追问]** 你为什么在 VRPTW 项目里选择 ALNS？比较过什么基线，哪些实际约束或计算预算影响了这个选择？
13. **[ALNS]** 从初始解到终止，完整讲述 ALNS 的破坏、修复、接受、算子选择和最佳解保存流程。
14. **[ALNS 算子]** 随机、最差和 Shaw 相关性移除分别在什么情况下有用？贪婪与 regret 插入分别解决什么问题？
15. **[修复算法]** 手推 regret-2 插入：怎样计算最佳与次佳插入代价，如何处理某客户没有可行插入位置？
16. **[项目架构]** 你的 `ProblemData`、`Route`、`Solution` 和搜索器分别负责什么？哪些状态必须在每次移动后更新？
17. **[项目实验]** 你的项目改善了什么指标？实例、时间预算、随机种子、基线和硬件是否一致？如何避免夸大改进？
18. **[列生成]** 写出 VRPTW 路线集合划分主问题，并解释为什么容量与时间窗不再显式出现在主问题中。
19. **[检验数]** 从主问题对偶变量推导路线检验数；若有“最多 $K$ 辆车”约束，公式还要增加哪一项？
20. **[定价]** 列生成中定价子问题到底寻找什么？为什么 VRPTW 定价是带资源约束的基本最短路（ESPPRC）？
21. **[标签]** VRPTW 标签至少保存哪些状态？从客户 $i$ 到 $j$ 时，成本、时间、载重和访问集合如何更新？
22. **[支配]** 两个到达同一节点的标签，满足什么条件才可安全删除其中一个？为什么访问集合的包含关系不能忽略？
23. **[路径松弛]** 基本路径、q-route、ng-route 有什么区别？放松“客户不可重复访问”会怎样影响定价速度与下界？
24. **[最优性]** 没有负检验数列时，列生成证明了什么？为什么还不能直接说原整数问题最优？
25. **[分支定价]** 列生成得到分数路线后如何分支？为什么直接对单个 $\lambda_r$ 分支可能使定价难以延续？
26. **[TSP 建模]** 只有每点度数为 2，为什么求出的可能不是一条完整巡回？举一个子回路例子。
27. **[DFJ]** 写出无向 TSP 的子回路消除约束，并说明内部边形式与割集形式为什么等价。
28. **[MTZ]** MTZ 次序变量怎样消除子回路？为什么 Big-M 可能导致 LP 松弛较弱？
29. **[数值建模]** 对 VRPTW 时间传递约束，如何给每条弧推导尽量紧的 $M_{ij}$，并删除根本不可能使用的弧？
30. **[求解器日志]** 给你一段 MIP 日志，如何区分“迟迟找不到可行解”和“已有好解但下界不涨”？各自优先检查什么？
31. **[回调]** TSP 的 lazy constraint 与 user cut 各在何时加入、解决什么问题？若只做整数子回路分离会怎样？
32. **[工具选择]** Gurobi MIP、OR-Tools Routing、自己写 ALNS 各适合什么任务？如何比较“找可行解”和“证明最优”的能力？
33. **[算例]** 你如何读取和核对 Solomon C101 / C102 文件中的仓库、客户、需求、时间窗、服务时长及车辆容量？
34. **[现场场景]** 给 100 个订单、20 辆车、配送时间窗和司机下班时间，你会如何定义目标、变量、硬约束、软约束及最初可运行的基线？
35. **[手写代码]** 写一个函数接收客户序列和实例数据，返回该路线的成本、完整时间表及第一个不可行原因；时间复杂度是多少？
36. **[手写代码]** 实现 Dijkstra 最短路并说明它的适用条件；为什么不能直接用于带负检验数弧的 ESPPRC？
37. **[手写代码]** 网格中只能向右或向下，求左上到右下路径数；若部分格子禁止经过，状态转移如何变化？
38. **[整数规划]** 分支定界如何利用上下界剪枝？初始可行解、强下界和分支变量选择各怎样影响搜索？
39. **[故障排查]** 算法返回“无解”时，你如何区分输入数据错误、模型写错、确实不可行和求解超时？
40. **[业务沟通]** 如果算法把总距离降低了 8%，却让一部分客户更晚收到货，你会怎样解释并重新定义评价指标？

## P1：高频深入（41–90）

41. **[构造法]** 推导 Clarke–Wright 节约值；合并路线时为什么必须检查端点、容量和车数？
42. **[局部搜索]** 对称 TSP 的 2-opt 如何改变路线？怎样用四条边计算距离增量，什么时候还必须重查时间窗？
43. **[VRP 算子]** Relocate、Swap、Or-opt、2-opt* 分别改变什么结构？跨路线移动后哪些缓存会失效？
44. **[容量割]** 对客户集 $S$ 推导 $x(\delta(S))\ge2\lceil d(S)/Q\rceil$；单客户路线对仓库边变量有什么特殊要求？
45. **[LP 松弛]** 一个满足度数约束的分数边解为何可能低估真实车数？怎样构造一个违反容量割的例子？
46. **[分离]** TSP 子回路割与 CVRP 容量割的分离难度有何不同？整数解和分数解的分离方法各是什么？
47. **[强化割]** Framed capacity、strengthened comb、multistar 这类 CVRP 割想补强基本 GCC 的哪类薄弱结构？
48. **[最小割]** 为什么可用最小割寻找违反无向 TSP 子回路约束的分数解？边容量应取什么？
49. **[梳状割]** SEC 都满足时为何仍可能出现分数解？梳状不等式利用了什么集合相交和奇偶结构？
50. **[1-tree]** 什么是 1-tree？它与 TSP 巡回是什么关系，最小 1-tree 如何求？
51. **[Held–Karp]** 节点乘子怎样修改 1-tree 边权？它提供的是上界、下界还是一条实际路线？
52. **[LKH]** LK 与固定 2-opt / 3-opt 的差别是什么？LKH 的候选边和 $\alpha$ 值为何能减少搜索？
53. **[遗传搜索]** EAX 如何利用父代边结构产生新巡回？它与简单地交换两个排列片段有何区别？
54. **[HGS / Split]** 给一个 giant tour，如何把最优容量可行分段转化为有向无环图最短路？若最多只能用 $K$ 辆车怎么办？
55. **[HGS]** 为什么 HGS 既维护解质量也维护种群多样性？暂时不可行解如何避免成为最终输出？
56. **[元启发式]** 禁忌搜索、模拟退火、ALNS 的“接受坏解 / 跳出局部最优”机制有何区别？
57. **[ALNS 自适应]** 怎样根据算子表现更新权重？如何防止一个早期表现好的算子垄断所有迭代？
58. **[Shaw 移除]** 如何定义客户相关性？距离、时间窗、需求各量纲不同，怎样归一化与调参？
59. **[接受准则]** 模拟退火接受概率中的温度如何初始化和冷却？温度过高或过低有什么迹象？
60. **[搜索诊断]** ALNS 长时间没有改进时，你会区分“破坏力度不够”“修复过于贪婪”“接受率过低”还是“初始解太差”？
61. **[增量评估]** 插入客户 $u$ 到 $(i,j)$ 之间时，距离增量为何易于 $O(1)$ 计算，而时间窗可行性可能影响整条后缀？
62. **[时间缓存]** 前向最早服务时间和后向可用 slack 能怎样加快插入评估？哪些边界条件会使所谓 $O(1)$ 检查不正确？
63. **[性能]** 纯 Python VRPTW 搜索器的常见热点在哪里？你会先 profile 哪些函数，再决定改数据结构或引入编译组件？
64. **[数据结构]** 距离矩阵、路线序列、访问集合分别适合怎样存储？何时使用列表、NumPy 数组或位集？
65. **[时间窗语义]** 时间窗限制的是到达时刻还是开始服务时刻？若在最晚时刻到达但服务跨窗，算不算可行？
66. **[动态行驶时间]** 若高峰时段行驶时间依出发时刻变化，原来的静态时间递推、标签支配和预处理要怎样改？
67. **[取送货]** 若订单有取货点和送货点，怎样加入先取后送、同车服务和沿路载重变化？
68. **[软时间窗]** 客户允许迟到并支付罚金时，模型与 ALNS 评价函数如何改？怎样避免把软约束误当硬约束？
69. **[异构车队]** 车辆容量、固定成本和行驶成本不同，主问题和定价如何表示“路线由哪类车执行”？
70. **[多仓库]** 多个仓库时，路线生成、客户覆盖及车队限制如何变化？
71. **[规模分析]** 为什么时间窗收紧可能同时减少可行路线、却也使可行初始解更难找到？
72. **[RMP 初始化]** 如何构造覆盖所有客户的初始列？若单客户路线也不可行，如何检测而不是盲目加大罚值？
73. **[对偶]** 覆盖等式与车辆数不等式的对偶变量符号有什么区别？你如何防止定价时漏掉车辆数对偶？
74. **[多列定价]** 一轮只加最负检验数路线，与加入多条负检验数路线，各有哪些速度与重复列问题？
75. **[列生成停滞]** 什么是列生成的尾效应？为什么主问题退化和对偶波动会导致许多轮微小改进？
76. **[对偶稳定]** 列生成中的对偶稳定化大致想限制什么波动？如何确保加速技巧不改变最终正确性？
77. **[q-route]** q-route 允许重复客户时，覆盖系数如何定义？为什么这种松弛列不能直接当作可执行路线？
78. **[ng-route]** 推导 ng-route 的局部记忆更新规则；邻域变大后，标签数和下界通常怎样变化？
79. **[割与定价]** 在集合划分 RMP 加 subset-row / rank-1 cut 后，为什么定价可能需要额外状态，而不能总靠简单修改边权？
80. **[分支]** 基于弧的分支怎样传入标签定价？禁止弧与强制弧分别如何影响可生成路线？
81. **[有效下界]** 若定价只用启发式算法且找不到负列，你能否宣称 LP 最优？若不能，怎样补上精确定价验证？
82. **[支配强化]** 资源下界、不可达客户集合和访问记忆如何帮助标签剪枝？添加新状态后如何重新检查支配条件？
83. **[双向标签]** 前向和后向标签在中间合并时，如何检查时间、载重、访问集合及检验数的一致性？
84. **[最短路]** Bellman–Ford、Dijkstra、标签算法各自处理什么问题？“带负边”与“带资源约束”是同一个难点吗？
85. **[LP 对偶]** 线性规划的对偶价格如何解释？在列生成中，为什么一条路线经过高对偶值客户可能更值得加入？
86. **[模型强化]** 除了收紧 Big-M，你还会怎样利用时间窗删除不可能的弧或增加有效不等式？
87. **[主问题]** Set Partitioning 的 $=1$ 与 Set Covering 的 $\ge1$ 有何差别？何时不能随意互换？
88. **[求解器]** 初始启发式路线怎样作为 MIP start？它可能改善什么，又不能保证改善什么？
89. **[性能定位]** 求解时间主要耗在根 LP、定价、分离、分支树还是 Python 回调时，你分别会采取什么措施？
90. **[实验设计]** 如何在 Solomon 算例上公平比较你的 ALNS、OR-Tools 和精确模型，并报告车辆数、距离、可行性、时间与随机波动？

## P2：进阶深挖与拓展（91–130）

91. **[DW 分解]** 从块角结构的原始模型推到 Dantzig–Wolfe 主问题；每个子块的凸组合约束起什么作用？

94. **[拉格朗日松弛]** 怎样从 TSP 的度数约束构造 1-tree 拉格朗日下界？乘子和定价对偶之间是什么关系？
95. **[行列生成]** “动态加约束”的分支切割与“动态加变量”的列生成有何对偶关系？两者能否同时使用？
96. **[网络流]** 给定一个分数 TSP 边解，你会用哪种最小割 / 最大流工具找违反 SEC 的集合？
97. **[不可行性诊断]** MIP 模型不可行时，IIS、冲突分析、逐层放松约束各能帮助你发现什么？
98. **[求解状态]** `OPTIMAL`、`TIME_LIMIT`、`INFEASIBLE`、`INF_OR_UNBD` 等状态下，怎样决定是否可以读取并交付一个路线解？
99. **[数值稳定]** Big-M 过大、浮点误差、距离舍入和容差设置可能怎样制造“模型可行但业务不可行”的结果？
100. **[Gap 计算]** 求解器报告的相对 Gap 与业务希望看到的“相对最好已知解改进率”有何区别？
101. **[车数下界]** 仅根据总需求能给出怎样的车辆数下界？加入时间窗后，还能构造什么更强的必要条件？
102. **[Split 细节]** 对固定 giant tour，若还要限制车辆数、最大路线时长和软时间窗，Split 动态规划状态与弧权应如何变化？
103. **[算例对比]** 面对 C101 与 C102 或同系列不同编号实例，你会先比较哪些数据分布，再解释算法表现差异？
104. **[基准一致性]** Solomon 距离和时间的计算、舍入、车辆数优先级若与论文不同，为何直接比较目标值可能失真？
105. **[对称性]** 同质车辆交换编号会造成怎样的模型对称性？有哪些可行的对称性处理办法？
106. **[有效约束]** 预处理删除弧与加入割平面分别改变什么？怎样确认一条删弧规则不会误删最优解？
107. **[优先顺序]** 某些客户必须先于另一些客户服务时，紧致模型、标签状态和 ALNS 修复各需改什么？
108. **[司机规则]** 加入司机休息、最长连续驾驶时间和班次限制后，标签资源与路线验证器如何扩展？
109. **[动态订单]** 新订单在车辆已出发后到达，你会怎样做局部插入或滚动重优化，并保留已承诺的服务？
110. **[不确定性]** 行驶时间不稳定时，你会选安全裕度、鲁棒优化、情景优化还是仿真评估？选择依据是什么？
111. **[仿真]** 静态最优路线在真实运营中表现差，如何用仿真区分需求预测、ETA、路线模型和执行偏差的贡献？
112. **[预测 + 优化]** ETA 模型的预测误差怎样传入时间窗可行性判断？只用平均预测值可能有什么后果？
113. **[ML 加速]** 学习模型若用于排序候选弧或标签，如何测试加速收益？如果直接剪枝，最优性证明受到什么影响？
114. **[成本校准]** 业务提供油费、人工、违约金和车辆固定成本，你怎样把它们转换成一致单位且可解释的目标？
115. **[未服务订单]** 若允许拒单并支付罚金，主问题如何加入未服务变量？罚金过低会产生什么行为？
116. **[线上系统]** 每天批量重算与实时滚动规划的延迟、稳定性和可解释性要求有何不同？
117. **[增量更新]** 一条路线临时取消或交通时间更新后，哪些数据结构和中间结果可以复用，哪些必须重算？
118. **[数据质量]** 订单缺坐标、时间窗颠倒、需求为负、重复 ID 时，数据管线应怎样拒绝或修复输入？
119. **[SQL]** 订单表与客户位置表连接后出现重复订单，你会怎样用 SQL 定位一对多连接并验证去重规则？
120. **[Python 数据处理]** 用 pandas 从订单明细生成客户、需求、时间窗及距离矩阵时，如何检查缺失、单位和索引错位？
121. **[图结构]** 稠密完全图与只保留候选弧的稀疏图分别适合哪些场景？稀疏化怎样影响精确性？
122. **[复杂度]** 为标签队列选择堆、双端队列或按资源分桶时，你如何根据扩展顺序与支配成本作取舍？
123. **[位运算]** 用位集维护已访问客户，与 Python `set` 相比，在包含判断、复制和支配比较上有何优缺点？
124. **[测试]** 除了标准算例，你会设计哪些极小反例验证时间窗等待、单客户路线、零需求、紧容量和重复访问？
125. **[手写代码]** 现场给一组无向边和一个整数 TSP 解，写出连通分量检测并返回违反的子集；复杂度是多少？
126. **[模型审查]** 给你一份陌生 VRPTW 数学模型，如何检查仓库起终点、客户恰好服务一次、Big-M 激活方向和时间循环漏洞？
127. **[临场建模]** 一项新业务同时有预约时间、司机技能、订单优先级和部分可拒订单，你会先给出什么最小可运行模型，再逐步加哪些限制？
128. **[缺失参数]** 业务拿不出准确服务时长或违约成本时，你会怎样估计、做敏感性分析并向业务说明决策风险？
129. **[跨团队沟通]** 运营希望更少车辆，客服希望更少迟到，算法算出两者不能兼得时，你如何给出可选择的权衡方案？
130. **[复盘]** 一个上线试点没达到离线算例效果，你会怎样从数据、目标、求解时间、系统接入和实际执行逐层复盘？

## 资料依据与使用建议

公开面经中，[美团运筹优化面经](https://www.nowcoder.com/feed/main/detail/0dd65c0a14ef46ccabcfdc265d14c1a6)明确提到 VRP 项目深挖、列生成 / 分支定价、模拟退火、场景建模和路径计数手写题；[秋招运筹面经汇总](https://www.nowcoder.com/feed/main/detail/79c080d9379f427aae832866e3909c5d)提到项目细节、求解器 Gap、单纯形、Dijkstra 与算法题；[个人求职记录](https://github.com/Licht123/-)记录了现场建模、线性化、分解算法和代码能力；[阿里 / 杉数面经](https://www.nowcoder.com/discuss/353156313175760896)涉及项目规模、求解器、方法选型、业务数据与 ML / OR 结合。英文一手经历也提到[检查模型错误、代码性能与业务边界](https://www.reddit.com/r/OperationsResearch/comments/1ear5hd/some_interview_questions_ive_run_into/)，以及[读求解器日志、现场业务建模](https://www.reddit.com/r/OperationsResearch/comments/1fo22o5/what_to_expect_in_an_interview_for_or_scientist/)；一份[运筹方向岗位描述](https://www.nowcoder.com/jobs/detail/434955)同时要求 VRP、MILP / 分解、启发式和工程实现。具体公司与团队侧重点会不同。

建议先把 **1–40 题**练到能在白板上讲清公式、画流程、举反例；再用 **41–90 题**准备技术深挖。每答一道项目题，准备一份真实的实例规模、运行时间、目标值、可行性检查结果和失败案例，比背算法名更有说服力。

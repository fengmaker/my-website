# 路径规划：从 TSP 到 VRPTW

路径规划的问题名字很多。阅读时先找出共同的骨架：谁从哪里出发、服务哪些客户、能否回到终点、目标是总距离还是车辆数。然后逐步增加约束，观察可行路线发生了什么变化。

| 问题 | 关键决定 | 比前一步多了什么 |
| --- | --- | --- |
| TSP（旅行商问题） | 一条回路按什么顺序访问所有城市 | 必须形成一条连通回路，不能出现小环 |
| VRP（车辆路径问题） | 用哪些车辆、各走哪条回路 | 多条路线共同覆盖客户 |
| CVRP（容量车辆路径问题） | 每辆车服务哪些客户 | 每条路线的总需求不能超过容量 $Q$ |
| VRPTW（带时间窗车辆路径问题） | 何时到达并开始服务 | 每位客户只能在允许的时间窗内接受服务 |

这些名称只是常见模型族。实际问题还可能有异构车辆、取送货、多个车场等条件；模型假设可以组合，不能仅凭缩写判断全部约束。

## 第一层：访问与连通性

在 TSP 中，弧变量 $x_{ij}$ 表示是否从 $i$ 直接到 $j$。每个节点各有一条入弧和出弧，只能保证“每点访问一次”，仍可能形成几条互不相连的小环。因此[子回路消除](TSP/第一阶段.md)是建模的关键。建议按[第一阶段](TSP/第一阶段.md)到[第四阶段](TSP/第四阶段.md)的顺序阅读，再比较[精确算法](TSP/精确算法.md)与[启发式算法](TSP/启发式算法.md)。

## 第二层：车辆与容量

进入 VRP 后，要决定每位客户由哪辆车服务，同时保持每条车路线的流量连续。CVRP 再要求同一条路线上的客户需求之和不超过车辆容量。先读 [CVRP 发展综述](CVRP/发展.md)和[第一阶段](CVRP/第一阶段.md)，再沿着[第二阶段](CVRP/第二阶段.md)、[第三阶段](CVRP/第三阶段.md)、[第四阶段](CVRP/第四阶段.md)看模型和算法；[启发式算法](CVRP/启发式算法.md)用于理解大规模实例中的快速构造与改进。

## 第三层：时间传播

VRPTW 中，客户 $i$ 的服务开始时间要落在 $[e_i,l_i]$ 内。若从 $i$ 到 $j$，应满足“在 $i$ 服务结束后行驶，再到 $j$ 开始服务”；早到可以等待，晚到违反硬时间窗。时间、载重和客户访问状态一起决定路线是否可行，所以求解比单纯比较距离复杂。

从 [模型建立](VRPTW/模型建立.md)入手，再读[路线规划](VRPTW/路线.md)和[精确算法](VRPTW/精确算法.md)。若要深入以完整路径为变量的求解方式，可先读[列生成与 DW 分解](../求解方法/列生成与DW分解.md)，再读本站的 [VRPTW DW 分解](VRPTW/dw分解.md)。[发展路线](VRPTW/发展路线.md)与[研究方案](VRPTW/研究方案.md)保留了进一步学习和实现的线索。

## 对照模型时的三个问题

1. 新增的约束究竟排除了哪种原本可行的路线？
2. 变量表示一条弧、一辆车的状态，还是一条完整路径？
3. 求解器给出的是可行方案、LP 下界，还是已经证明的整数最优解？

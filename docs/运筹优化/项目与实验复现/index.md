# 个人作品集与实验记录

这里记录我已经实现的优化项目：从问题建模、独立校验，到搜索算法、性能诊断与可追溯实验。两个项目都已有代码和历史实测；以下结果依据固定版本归档整理，数据协议与限制在各项目页说明。

<div class="grid cards" markdown>

- **GMRP-ALNS · 机器重分配**

    ROADEF/EURO 2012，v1.0.0 / M0～M8。增量状态、VND、ALNS 与 Restricted CP-SAT Repair。

    **660 条归档观察**，全量 Validator 与官方 checker 回执一致；一秒请求预算下，简单方法优于复杂搜索，208 次超容差如实保留。

    [项目、结果与复现](GMRP-ALNS.md)

- **VRPTW Solver · 时间窗车辆路径**

    Solomon，M0～M12。独立验证、可行 ILS、限预算减车与 C++17 / pybind11 局部搜索。

    **56 实例 × 2 预算 × 4 求解器**；自研两档均 56/56 可行，结果同时记录车数、同车距离与实际时间。

    [项目、结果与复现](VRPTW-Solver.md)

## 从哪一层查看成果

| 关注点 | GMRP-ALNS | VRPTW Solver |
| --- | --- | --- |
| 问题与约束 | 机器资源、服务分布与依赖、迁移成本 | 客户覆盖、容量、时间窗、车辆优先目标 |
| 工程实现 | Parser、全量 oracle、增量 apply / undo、精确修复 | 独立 Validator、CLI、精确增量评价、原生热点后端 |
| 实验设计 | 预冻结 20 实例、5 种子、短预算与消融 | 56 实例、四求解器、0.5 / 5 秒、协议分离 |
| 主要结论 | ALNS 未超过简单 Relocate / VND；受限修复收益不稳定 | 延长预算改善减车与距离，仍保留困难实例与对照配置限制 |
| 可核对产物 | 660 行观察、主方法 / 逐实例汇总、来源哈希 | 448 行运行记录、四方汇总、路线与轨迹示例 |

GMRP 的改善率相对初始 assignment，VRPTW 的距离 Gap 相对指定 PyVRP 配置且仅在同车数时计算；两个项目的百分比不作横向排名。已实现与已证明最优分别表述，单机短预算观察不扩展成通用性能结论。

## VRPTW 的推进顺序

1. 明确问题假设、目标顺序与数据格式，先实现可行性校验和目标重算。
2. 建立可重复运行的小实例模型或构造基线，保存代码版本与命令。
3. 按开发方案实现并核对邻域、破坏修复与 ALNS；精确求解路线另外记录主问题、定价与界。
4. 按[实验规范](../求解器与工程实现/实验规范.md)比较目标、时间与稳定性，保留失败分析。

[专题与实验记录模板](./专题与实验记录模板.md)将文献学习、自己的实现和实测结果分开。AHC、开源算法复现及跨问题性能对比可在有代码与记录后加入本板块。

# 专题与实验记录模板

新建问题专题或实验记录时采用下面的结构。尚未做的部分标记“计划”或“待运行”，引用的结果标明作者与来源；不要用占位数值充当实测数据。

## 1. 问题概述

- 业务背景、数学定义、输入输出、约束与目标优先级。
- 数据集来源、实例规模、可行性条件与适用范围。

## 2. 数学建模

- 集合、参数、变量、目标与约束。
- 模型选择依据、松弛与边界条件；链接到[基础理论](../基础理论与建模/index.md)。

## 3. 算法与文献

- 基线和拟比较方法、原文来源及阅读日期。
- 链接到[算法原理](../求解算法体系/index.md)，说明在当前问题中如何应用。

## 4. 个人实现

- 代码仓库、commit、核心数据结构与算子。
- 可行性校验、目标重算、关键边界例子及运行命令。

## 5. 实验对比

- 按[实验规范](../求解器与工程实现/实验规范.md)记录环境、参数、预算与种子。
- 放入原始日志、结果表、时间、目标、界或参考差距及其定义。
- 记录消融、失败案例和未完成运行；未运行时只写实验设计与验收标准。

## 6. 个人总结

- 实际观察到的瓶颈、有效改动与证据。
- 当前局限、适用场景与下一步实验。
- 区分文献结论、自己的观察与尚未验证的假设。

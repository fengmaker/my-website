# 标签索引

标签提供跨导航的检索入口。目前先覆盖基础入门、核心算法、TSP / CVRP / VRPTW、CP-SAT 与项目方案等重点文章，后续随整理补齐。

## 标签约定

- 问题使用标准缩写，例如 `TSP`、`CVRP`、`VRPTW`、`JSP`、`FJSP`。
- 方法使用统一名称，例如 `精确算法`、`列生成`、`DW 分解`、`分支定价`、`启发式算法`、`ALNS`、`CP-SAT`。
- 内容类型按需使用 `基础理论`、`建模`、`学习路线`、`项目方案`，标签描述文章内容，项目状态以正文说明为准。
- 每篇选取少量相关标签；沿用已有名称，避免中英文同义词形成重复索引。

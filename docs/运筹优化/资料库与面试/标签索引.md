# 标签索引

标签提供跨导航的检索入口。已覆盖运筹优化目录内的内容页与运筹学习地图；本索引和参考许可页作为工具页不加标签。其他知识栏目暂不纳入本轮覆盖。

## 标签约定

- 问题使用标准缩写，例如 `TSP`、`CVRP`、`VRPTW`、`JSP`、`FJSP`。
- 方法使用统一名称，例如 `精确算法`、`列生成`、`DW 分解`、`分支定价`、`启发式算法`、`ALNS`、`CP-SAT`。
- 内容类型按需使用 `基础理论`、`建模`、`学习路线`、`项目方案`、`作品集`、`实验结果`，标签描述文章内容，项目状态以正文说明为准。
- 每篇选取少量相关标签；沿用已有名称，避免中英文同义词形成重复索引。

### 常见名称的统一写法

| 统一标签 | 不作为新标签使用的别名 |
| --- | --- |
| `CP-SAT` | `CPSAT`、`CP SAT` |
| `DW 分解` | `DW分解`、`Dantzig-Wolfe 分解` |
| `分支定价` | `Branch and Price` |
| `启发式算法` | `启发式`、`Heuristics` |
| `GMRP` | `GMRP-ALNS`（项目名称放在标题中） |
| `实验结果` | `实测结果` |

统一词表、别名提示与覆盖范围维护在仓库 `config/tags.yml`，离线检查会报告缺失标签、未知名称，并对已知别名提示对应的统一名称。新增文章沿用词表；遇到历史别名时随文章维护逐步修正，避免重复创建同义标签。标签只说明主题，真实实验与项目完成状态以正文为准。

# JSSP 第 12 节来源核验

核验日期：2026-10-12。以下优先使用出版社页面、作者稿或论文全文；“Big Valley”相关结论均按具体问题、邻域与距离定义限定范围。

| 议题 | 来源可支持的主张与限制 |
|---|---|
| 优秀解集合与多样性 | Glover、Laguna、Martí 的作者稿将 Reference Set 作为少量参考解的集合，并明确允许解因提升集合多样性而入选，即使其目标值逊于已有成员；初始化还给出按最大化到集合最小距离来挑选多样解的方案。[作者稿《Scatter Search and Path Relinking: Foundations and Advanced Designs》](https://leeds-faculty.colorado.edu/glover/aassprad.pdf)。这是散布搜索/PR 的设计原则，不是“多样性必然带来更优解”的定理，也不表示每种 PR 算法都维护同样的精英集。 |
| Boese–Kahng–Muddu 的 Big Valley | 原始论文研究的是 **TSP 与图二分**，不是 JSSP。作者在抽样得到的局部最优解上观察成本与距离的相关性，并将其解释为局部最优解呈 Big Valley 分布的经验证据；论文结论用的是“evidence”，并未证明所有实例都有这种结构。[论文全文（Operations Research Letters, 1994）](https://vlsicad.ucsd.edu/Publications/Journals/j15.pdf)。距离也依对象而异：TSP 的 bond distance 是 $n$ 减两条 tour 的公共无向边数；论文证明它与真正的 2-opt 最少步数 $d$ 满足 $b/2\le d\le b$，这条不等式是定理，但 **Big Valley 本身仍是经验观察**。图二分距离则定义为把一侧顶点交换到另一侧的 2-interchange 次数。 |
| Reeves–Yamada 的对象与距离 | 这项研究针对 **排列流水车间 PFSP**，不能直接当作 JSSP 的 Big Valley 证据。论文把 Big Valley 明确称作非正式概念：局部最优解倾向彼此接近并接近全局最优解；它考察由交换（EX）和移位（SH）邻域诱导的景观，并在 Taillard 测例上报告经验结果。[论文作者稿（Evolutionary Computation, 1998）](https://citeseerx.ist.psu.edu/document?doi=16a79a12ec22bc7cdeb5dfaab78c7735c8505775&repid=rep1&type=pdf)，[期刊 DOI](https://doi.org/10.1162/evco.1998.6.1.45)。作者讨论的距离包括 precedence 距离（排列中 job 两两先后关系不一致的数量）和 position 距离（各 job 位置差绝对值之和）；它们是排列距离，不能和 TSP 的边差距离或 JSSP 的机器位置差距离混称。论文指出 EX 邻域的最少交换数较易定义，SH 的操作距离较难计算，并在其实验中使用 precedence 距离。 |
| Nowicki–Smutnicki 2005 | 出版社摘要确认该论文针对以 makespan 为目标的 JSSP，提出以 Big Valley 现象为依据、使用若干 path relinking 机制并利用邻域理论性质的近似算法。[出版社论文页](https://doi.org/10.1007/s10951-005-6364-5)。截至核验日，出版社可读页仅提供摘要与书目信息，未能通读全文；因此不把 Big Valley 写成定理，也不据此推断 PR 路径的具体距离或可行性。Peng、Lu、Cheng 的 JSSP 论文回顾说，2005 年 i-TSAB 加入基于 PR 的 new initial solution（NIS）生成器；这表明该用法是为 tabu search 产生新起点，不应与下述“对每个路径候选做 TS”的另一种 hybrid 结构混为一谈。[作者稿全文（arXiv, 2014；后发表于 2015）](https://arxiv.org/pdf/1402.5613)，[期刊 DOI](https://doi.org/10.1016/j.cor.2014.08.006)。 |
| Path Relinking 的引导与可行性 | Glover、Laguna、Martí 将 PR 描述为在 **邻域空间** 连接起始解与引导解的轨迹；每步逐渐加入引导解的属性，或缩小双方属性距离。它并不要求按目标值单调改善，也没有一个跨问题通用的距离公式。[作者稿《Scatter Search and Path Relinking: Advances and Applications》](https://citeseerx.ist.psu.edu/document?doi=3c7a5df6ddea25b2d062fa78e8f6434a581dc6dc&repid=rep1&type=pdf)，[作者稿《Scatter Search and Path Relinking: Fundamentals》](https://leeds-faculty.colorado.edu/glover/ssandprfundamentals.pdf)。在 Peng 等人的 JSSP TS/PR 中，排程表示为各机器上的工序排列，$\mathrm{Dis}(S^I,S^G)$ 是两解各机器排列中 **位置不一致的总数**（向量化排列的 Hamming 型距离）；路径通过交换同一机器上的工序逐步匹配引导解的位置。这是该论文定义的距离，不是 Kendall precedence 距离或 makespan 差。[作者稿全文，定义与算法见第 7–11 页](https://arxiv.org/pdf/1402.5613)。 |
| JSSP 可行性与 hybrid 分工 | PR 的中间解不保证可行，除非具体表示与移动规则保证可行。Peng 等人明确指出，其随机交换可能违反 job precedence，使 PathSet 中候选不可行；他们先修复候选，再做少量 TS。短 TS 将候选改善至局部最优以筛选参考解；选出最优候选后，再用长 TS 深化搜索，最后用参考解更新种群。因此应写成“PR 产生并引导候选、修复恢复可行、TS 局部强化”，并注明这是该算法的职责划分，不是所有 hybrid 的固定模板。[作者稿全文](https://arxiv.org/pdf/1402.5613)。JSSP 中较早的 GRASP/PR 实例由 Aiex、Binato、Resende 提出，论文把 PR 用作连接高质量解的强化策略。[出版社论文页](https://doi.org/10.1016/S0167-8191(03)00014-0)，[作者稿全文](https://citeseerx.ist.psu.edu/document?doi=9d2509d4e5305988b6548cc6714d4e91624e4d73&repid=rep1&type=pdf)。 |
| Pardalos–Shylo 的归属 | Pardalos 与 Shylo 的 2006 JSSP 论文题名和摘要说明其提出的是 **Global Equilibrium Search（GES）** 算法；不应将其列为 path relinking 的原始论文或 PR/JSSP 实例。[出版社 DOI](https://doi.org/10.1007/s10287-006-0023-y)。JSSP 的直接 PR 实例可引用 Aiex 等（2003）或 Peng 等（2015）。 |

**写作边界：** Big Valley 只能表述为特定景观下、特定距离与样本观察到的经验结构；不能说成已证明的 JSSP 普遍性质。PR 的“朝引导解前进”指逐步加入其解属性/缩小表示距离，并不等于 makespan 单调变好或中间排程始终可行。先说明解表示和距离，再说明是否保可行、是否修复，以及 TS 在该 hybrid 中负责候选强化还是只负责从 NIS 起点继续局部搜索。

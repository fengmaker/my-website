# 数据集与实验规范

本页规定以后新增个人实验时应记录的内容。现有学习笔记中的示例、原作者实验与本站自行运行的结果应分别注明来源。

## 数据与环境

| 项目 | 必须记录 |
| --- | --- |
| 数据集 | 来源、版本、实例名、规模、下载日期或文件校验值，以及再分发许可 |
| 问题假设 | 车辆与仓库、容量、时间窗、服务时长、取整方式和距离定义 |
| 目标 | 单一目标或字典序目标；例如先最小化车数再最小化距离时分别记录两项 |
| 运行环境 | CPU、内存、操作系统、语言、求解器与依赖版本、线程数 |
| 代码与参数 | 仓库链接、commit、运行命令、配置、随机种子、时间上限和停止条件 |
| 基线 | 模型或算法版本、相同输入与计算预算、参考值及其来源 |

路径问题可从已有的 [VRPTW 开发方案](../路径规划/VRPTW/研究方案.md)梳理所需算例。采用外部标准数据集时，在实验记录中写明具体来源与解析规则；本站目前未随重构新增数据集下载或实测结果。

## 结果与比较

- 先验证解可行：客户覆盖、容量、时间窗、路线连续性和目标重算都应有独立校验。
- 精确算法记录可行解值、上下界、求解状态、运行时间和 Gap 定义。超时与已证明最优分别标注。
- 启发式记录每次运行的种子、目标值、时间及可行性，汇总最好值、均值和离散程度。
- 与参考最优值或最好已知值比较时注明来源；相对差距不能写成“已证明的最优性 Gap”。
- 分级目标先比较最高优先级指标，再比较下一项，避免将不同车数的距离直接排名。
- 做算子消融或参数对比时，固定数据、预算与其余配置，保留失败或不可行运行。

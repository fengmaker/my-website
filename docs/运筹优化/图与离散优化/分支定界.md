# 分支定界

分支定界（Branch and Bound）用两类信息搜索整数解：**松弛问题提供界，可行整数解提供当前最好方案**。下面统一以最小化为例。

## 上界、下界和剪枝

整数可行解的目标值是全局最优值的上界，通常称为 incumbent。一个节点上的 LP 松弛最优值是该节点所有整数解的下界。如果节点下界已经不小于 incumbent，该节点不可能产生更好的解，可以剪枝。

每个节点的处理顺序如下：

1. 求解该节点的 LP 松弛。若不可行，直接剪枝。
2. 若松弛值不小于当前上界，按界剪枝。
3. 若 LP 解恰好满足整数条件，用它更新上界，然后结束该节点。
4. 否则挑一个分数变量 $x_k^*=v$，建立 $x_k\le\lfloor v\rfloor$ 与 $x_k\ge\lceil v\rceil$ 两个子节点。

例如 $x_k^*=2.4$ 时，两个子节点分别要求 $x_k\le2$ 和 $x_k\ge3$。所有整数可能性都被保留，而当前的分数解被排除。重复以上过程，直到没有待处理节点，或上下界的差距达到预设容差。

## 为什么建模质量影响速度

若 LP 松弛允许许多与实际整数解相距很远的分数方案，下界会偏低，搜索树可能很大。更紧的有效不等式、适当的变量上下界和更好的初始可行解，往往都能减少搜索节点。但更强的松弛也可能使单个节点求解更慢，实际需要比较总求解时间。

TSP 的度数约束允许多个不相连的小环，所以需要[子回路消除约束](../../TSP/第一阶段.md)。这类约束收紧松弛；在分支定界中动态添加有效不等式，便进入分支切割的思路。路径模型规模进一步增大时，还会遇到[列生成](../求解方法/列生成与DW分解.md)和分支定价。

## 读求解日志时看什么

对最小化模型，常见指标是当前可行解值（上界）、当前证明的下界、相对 gap、已探索节点数和耗时。如果停止时仍有 gap，得到的是一个有质量保证的可行解，但尚未证明最优。

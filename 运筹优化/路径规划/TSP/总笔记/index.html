    TSP 总笔记：模型、精确算法与启发式搜索¶

    整合本文件夹的四篇阶段笔记、精确算法和启发式算法。以下以对称 TSP 的无向图为主线；原笔记中有向模型的入度、出度写法与这里的无向度数写法不能直接混用。

    1. 问题与一条总线¶

    给定无向图 \(G=(V,E)\)、边成本 \(c_e\)，寻找经过每个城市恰好一次的最小成本闭合巡回。令 \(x_e\in\{0,1\}\) 表示是否选择边 \(e\)，\(E(S)\) 表示端点都在 \(S\) 内的边，\(\delta(S)\) 表示恰有一个端点在 \(S\) 内的边。合法巡回满足每点度数为 2，且整张图连通。

    方法 核心对象 解决的问题 主要代价
    指派 / 2-匹配松弛 边 给出容易求解的起点 允许多个子回路
    DFJ、MTZ 集合割、访问次序 消除子回路 DFJ 约束指数多；MTZ 松弛偏弱
    分支切割 动态生成的割 只处理当前违反的约束 需要分离算法与回调
    1-tree / Held–Karp 生成树加两条根边 构造强下界与候选边信息 仍需处理整数性
    Concorde 式求解 多类割、分支与工程优化 证明 TSP 最优性 实现复杂
    LK / LKH、EAX 完整巡回 快速寻找高质量解 通常不提供最优性证明

    2. 从度数约束到完整模型¶

    2.1 为什么仅有度数不够¶

    最基础的无向模型是

    \[\min\sum_{e\in E}c_ex_e,\qquad x(\delta(i))=2\ (i\in V),\qquad x_e\in\{0,1\}. \]

    它可能选出几个互不相连的环。对应的有向模型要求每点入度与出度各为 1，也同样可能出现多个子回路。

    2.2 DFJ：对子集要求连通¶

    对任意非空真子集 \(S\subset V\)，加入子回路消除约束（SEC）：

    \[x(\delta(S))\ge 2.\]

    由 \(x(\delta(i))=2\) 可得 \(2x(E(S))+x(\delta(S))=2|S|\)，所以等价形式为 \(x(E(S))\le |S|-1\)。有向图中对应的割集右端为 1，并需同时保留入度、出度约束。

    DFJ 松弛通常比 MTZ 紧，但度数约束加全部 SEC 仍不等于完整的 TSP 多面体，分数解仍可能存在。困难在于子集数量随 \(|V|\) 指数增长，因而实际求解会动态加割。

    2.3 MTZ：用访问次序阻止小环¶

    在有向图中固定根节点 1，给其余节点设置次序 \(u_i\)。一种常用写法为

    \[1\le u_i\le n-1\quad(i\ne1),\qquad u_i-u_j+(n-1)x_{ij}\le n-2\quad(i,j\ne1,\ i\ne j).\]

    若 \(x_{ij}=1\)，则 \(u_j\ge u_i+1\)，因此不可能形成不含根节点的有向环。MTZ 只有 \(O(n^2)\) 条约束，便于教学和小规模基线；Big-M 项使其 LP 松弛往往较弱。比较模型时，应统一图的方向、成本定义、机器、求解器和停止条件。

    3. 分支切割：按需生成 DFJ 约束¶

    先求解度数模型，再检查当前解：

    1. 整数候选解：找到被选边形成的连通分量；若不止一个分量，就对各真子集加入 SEC。这类约束在回调中作为 lazy constraint，负责阻止错误巡回被接受。
    2. 分数 LP 解：把 \(x_e^*\) 当成边容量，寻找 \(x^*(\delta(S))<2\) 的割并加入。这类 user cut 用于增强下界，但仅做整数分离也能保证最终解正确。
    3. 没有可加入的割：若解仍为分数，则分支；每个分支节点继续执行分离。

    整数分离可用图遍历；分数 SEC 分离可用无向最小割。实现回调时，若变量只按 \(i<j\) 存一份，求 \(x(E(S))\) 也必须只枚举一次无向边。原第二阶段示例对同一边遍历了 \((i,j)\) 和 \((j,i)\)，实际代码中会重复计数。它的 LazyConstraints=1 设置和 MIPSOL 检查思路可以保留，表达式需要按此修正。

    4. 1-tree 与 Held–Karp 下界¶

    选一个根节点 \(r\)。在 \(V\setminus\{r\}\) 上取一棵生成树，再从 \(r\) 选两条不同的边，就得到一棵 1-tree。每条 TSP 巡回都是一棵所有节点度数均为 2 的 1-tree；反之，一棵 1-tree 只有在各点度数为 2 时才是巡回。

    令 \(\mathcal T\) 为所有 1-tree，\(d_i(T)\) 为 \(T\) 中节点 \(i\) 的度数，\(c(T)\) 为边成本之和。原第三阶段的列生成写法可整理为

    \[\begin{aligned} \min\quad &\sum_{T\in\mathcal T}c(T)\lambda_T\\ \text{s.t.}\quad &\sum_T d_i(T)\lambda_T=2\quad(i\in V),\\ &\sum_T\lambda_T=1,\qquad \lambda_T\ge0. \end{aligned}\]

    边变量由 \(x_e=\sum_{T\ni e}\lambda_T\) 恢复。若度数约束对偶为 \(\pi_i\)，凸组合约束对偶为 \(\mu\)，则新 1-tree 的检验数为

    \[\bar c(T)=c(T)-\sum_i\pi_i d_i(T)-\mu =\sum_{(i,j)\in T}(c_{ij}-\pi_i-\pi_j)-\mu.\]

    因此定价只需在修正边权 \(\tilde c_{ij}=c_{ij}-\pi_i-\pi_j\) 下求一棵最小 1-tree：非根节点上求最小生成树，再给根节点接两条最便宜的边。若最小检验数不再为负，当前列生成 LP 达到这个松弛的最优值，得到 Held–Karp 型下界；它不是 TSP 整数最优解的证明，除非上下界闭合。等价的拉格朗日写法是 \(\max_\theta\min_{T\in\mathcal T}[c(T)+\sum_i\theta_i(d_i(T)-2)]\)，这里 \(\theta_i=-\pi_i\)。这样可避免原文中关于乘子正负的反复解释。

    若将此松弛置于分支定价框架，可以对分数的原始边变量 \(x_e\) 分支，并让子问题遵守禁用或强制边的条件。对 TSP 而言，这是一条理解下界和分解的路线；原笔记提到的 VRP 集合划分定价则是另一种路径列模型，不应将两者当成同一个子问题。

    5. 更强的割与 Concorde 思路¶

    SEC 无法消除所有连通的分数解。梳状不等式刻画额外的奇偶结构：梳把 \(H\) 与奇数个、至少 3 个两两不交的梳齿 \(T_1,\ldots,T_k\) 相交，且每个梳齿都有一部分在 \(H\) 外。对合法巡回有

    \[x(\delta(H))+\sum_{h=1}^{k}x(\delta(T_h))\ge 3k+1.\]

    利用每点度数为 2，可改写为原第四阶段采用的内部边形式：

    \[x(E(H))+\sum_{h=1}^{k}x(E(T_h)) \le |H|+\sum_{h=1}^{k}(|T_h|-1)-\frac{k+1}{2}.\]

    实际精确求解器会综合初始巡回、SEC 及其他有效不等式的分离、割池管理、分支和搜索控制。Concorde 的特点是强分支切割的系统工程；不能把它概括成“只加梳状割”，也不能假定所有连通分数解只靠梳状割就能处理。

    6. 启发式：先找到好巡回，再持续改进¶

    • 构造：最近邻等方法快速给出初始巡回；质量随实例变化。
    • 2-opt / 3-opt：分别删去 2 / 3 条边并重接。对对称欧氏 TSP，2-opt 的典型操作是反转一段序列；更大邻域提高改进机会，也增加搜索量。
    • LK（Lin–Kernighan）：采用可变深度的边交换，不预先固定 \(k\)。候选边和增益判定控制搜索规模。
    • LKH 系列：用 1-tree 相关的 \(\alpha\) 值构造有希望的候选边集，结合多次局部搜索；\(\alpha\) 是边的结构性评分，不是“进入最优解的概率”。LKH-3 扩展了支持的问题类型，但具体变体仍需相应变换和可行性 / 罚函数设计。
    • EAX：通过父代边集的交替环重组巡回，是另一条高质量 TSP 启发式路线。

    原启发式算法后半还讨论 Relocate、Swap、Or-opt、跨车 2-opt、Shaw 移除与后悔插入。它们主要服务于多车 VRP*：单路线 TSP 可先掌握构造、2-opt、LK / LKH；进入 CVRP、VRPTW 后再处理跨路线的容量和时间窗可行性。

    7. 学习与复现顺序¶

    1. 在同一小实例上实现度数模型、MTZ、整数 SEC 回调，检查巡回与目标值。
    2. 记录根节点 LP 下界和整数最优值，再尝试分数 SEC 分离，观察下界变化。
    3. 独立实现最小 1-tree 与乘子修正边权，理解 Held–Karp 下界。
    4. 用最近邻加 2-opt 建立启发式基线，再学习 LK / LKH 候选边思想。
    5. 比较算法时同时报告可行巡回成本（上界）、有效下界、运行时间与终止条件；只有上下界闭合才声称证明了最优性。

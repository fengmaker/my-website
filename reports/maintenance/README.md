## 在另一个实际网络复测

先在该网络运行严格构建，再执行以下命令。把网络标签改为真实接入方式，例如家庭宽带或手机热点；标签本身不会改变网络。保留同样的 URL、样本数与超时，使用不同输出名。测量结果需要结合各次失败情况比较，不能只比较成功样本中位数。

```powershell
python -m mkdocs build --strict
python -X utf8 -B scripts/measure_site.py --measure-network --samples 5 --timeout 12 --network-label "第二个实际网络名称" --url https://unpkg.com/mathjax@3/es5/tex-mml-chtml.js https://fengmaker.github.io/my-website/ --output reports/maintenance/performance-second-network.json --report reports/maintenance/performance-second-network.md
```

`@3` 会随上游主版本内的发布变化；跨日期复测时，应同时记录最终资源版本或内容散列，再判断是否仍为同一资源。后续浏览器验收要记录浏览器版本、缓存状态、设备与页面，并另测首屏和即时导航后的公式渲染。

## 外链结果与处理原则

完整结果见 [external-links.md](external-links.md) 与 [JSON](external-links.json)。脚本忽略代码示例，去掉 URL 片段后合并相同资源，保留来源文件与行号。HEAD 返回 404/410 时使用有限 GET 复核；403、429、TLS 与其他网络失败不按永久失效处理。跳转到登录页或验证码页也不保证内容可读，仍需人工核对。

本次 132 个去重 URL 全部检查：113 个直接成功、6 个成功跳转、10 个访问受限、2 个 TLS 错误、1 个超时；没有经 GET 复核的 404/410。微信两项跳转到验证码，Overleaf 跳转到登录页，列为人工复查；TLS 和超时应在其他网络复查，不关闭证书验证。

JSP 笔记的一处 DOI 由 `https://doi.org/doi:10.1111/poms.13501` 修正为 `https://doi.org/10.1111/poms.13501`，与[出版方记录](https://journals.sagepub.com/doi/full/10.1111/poms.13501)核对一致。修正后只复查此地址，仍返回 403；保留正确引用，不把访问限制认定为论文失效。报告注明全量扫描与单项复查时间。

独立 GitHub Actions 每周运行并保留 30 天报告，默认不阻断发布；推送 workflow 后生效。日常先查看来源位置和最终 URL，再决定修复、替换或保留说明，不能直接批量删除引用。`--strict` 适合人工核对后按需启用，本轮没有接入发布阻断。

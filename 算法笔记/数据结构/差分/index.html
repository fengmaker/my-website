    差分数组¶

    根据灵茶山艾府的这篇《图解差分数组》文章，差分数组的核心知识点总结如下：

    1. 定义¶

    对于原数组 \(a\)，其差分数组 \(d\) 定义为： * \(d[0] = a[0]\) * \(d[i] = a[i] - a[i-1]\) (当 \(i \ge 1\) 时)

    即：差分数组存储的是原数组相邻元素的差值（右边减左边）。

    2. 核心性质¶

    差分数组 \(d\) 与原数组 \(a\) 存在互逆关系（类似微积分中的求导与积分）： * 性质 1（还原）： 从左到右对差分数组 \(d\) 求前缀和，即可还原得到原数组 \(a\)。

    3. 核心操作（区间修改）¶

    这是差分数组最主要的应用场景。 * 目标： 将原数组 \(a\) 的连续子数组 \(a[i], a[i+1], \dots, a[j]\) 中的每个元素都加上 \(x\)。 * 差分操作： 只需要修改差分数组 \(d\) 中的两个数值即可达到等价效果： 1. \(d[i] += x\) （表示从下标 \(i\) 开始，之后的数都加上了 \(x\)） 2. \(d[j+1] -= x\) （表示从下标 \(j+1\) 开始，抵消掉之前加上的 \(x\)，从而限制影响范围只在 \(i\) 到 \(j\) 之间）

    4. 算法复杂度¶

    • 区间修改： \(O(1)\)。无论区间长度如何，只需要修改两个元素。
    • 还原数组： \(O(n)\)。需要遍历一次差分数组求前缀和。

    5. 直观理解¶

    • 微积分视角： 差分数组类似于对原数组“求导”，还原数组类似于“积分”。
    • 影响视角： \(d[i]\) 的值可以理解为“把下标 \(\ge i\) 的所有数都加上 \(d[i]\)”。因此，为了只改变 \([i, j]\) 区间，需要在 \(j+1\) 处减去同样的值来“截断”这种影响。

    根据你提供的基础题目和代码，这类【差分数组】（Difference Array）题目的核心在于将“区间修改”转化为“单点修改”。

    以下是针对该题型的写法总结、踩坑点以及题型直觉：

    一、 题型直觉：什么时候用差分数组？¶

    [!summary] 核心判据 题目涉及频繁的“区间修改”（例如：将下标 l 到 r 的元素都加上 x），且查询操作通常发生在所有修改完成之后。

    • 典型关键词：
      • “覆盖”、“重叠”（如：被覆盖了多少次）
      • “区间增加/减少”（如：上下车、航班预订）
      • “某个时间段内的最大并发量”（如：人口统计）
      • “操作会对之后所有元素产生影响”（如：2960题）

    三、 踩坑点 (Mines) 💣¶

    1. 数组越界 (Index Out of Bounds)

      • 痛点：这是差分数组最容易报错的地方。操作是 diff[r + 1]。如果 r 已经是数组最后一个元素的下标，r+1 就会越界。
      • 解法：初始化 diff 数组时，长度至少设为 max_index + 2。多给两个空间永远比 debug 越界划算。

    2. 区间定义的开闭性

      • 痛点：题目说是 [l, r] 还是 [l, r)？
      • 解法：
        • 闭区间 [l, r]（LeetCode 最常见）：diff[l] += x, diff[r + 1] -= x。
        • 左闭右开 [l, r)：diff[l] += x, diff[r] -= x。

    3. 偏移量 (Offset)

      • 痛点：题目下标可能是负数或很大（如年份 1950-2050）。
      • 解法：找到最小基准值（OFFSET），访问时用 diff[index - OFFSET]。

    4. 还原后的索引对齐

      • 痛点：accumulate 出来的数组长度和原数组对不上。
      • 解法：如果使用了 N+2 的策略，还原后的数组 s 也是 N+2 长度。通常 s[i] 对应原问题的下标 i。如果原题是 1-based，要注意 s 的下标 0 位置通常是 0。

    四、 核心结论 (One-Liner Summary)¶

    [!summary] 差分数组心法 看到“区间整体修改”，立刻想到差分数组；初始化长度开大 2 位保平安 (N+2)；区间闭合看右界，闭区间 r+1 减，开区间 r 减；还原数组用前缀和。

    class Solution:

    def numberOfPoints(self, nums: List[List[int]]) -> int:

        max_end = max(end for _, end in nums)

        diff = [0] * (max_end + 2)  # 注意下面有 end+1

        for l,r in nums:

            diff[l] += 1

            diff[r + 1] -= 1

        return sum(s > 0 for s in accumulate(diff))

    class Solution:

    def isCovered(self, ranges: List[List[int]], left: int, right: int) -> bool:

        diff = [0] * 52

        for l,r in ranges:

            diff[l] += 1

            diff[r + 1] -= 1

        cur = 0

        for i in range(1,51):

            cur += diff[i]

            if left <= i <= right and cur <= 0:

                return False

        return True

    class Solution:

    def maximumPopulation(self, logs: List[List[int]]) -> int:

        diff = [0] * 101

        for b,d in logs:

            diff[b - 1950] += 1

            diff[d - 1950] -= 1

        s = list(accumulate(diff))

        max_pop = max_year = 0

        for i in range(101):

            if s[i] > max_pop:

                max_pop = s[i]

                max_year = i

        return max_year + 1950

    2960. 统计已测试设备

    题目描述（节选）：

    给你一个长度为 n 、下标从 0 开始的整数数组 batteryPercentages ，表示 n 个设备的电池百分比。

    你的任务是按照顺序测试每个设备 i，执行以下测试操作：

    • 如果 batteryPercentages[i] 大于 0：
      • 增加 已测试设备的计数。
      • 将下标 j 在 [i + 1, n - 1] 的所有设备的电池百分比减少 1，确保它们的电池百分比 不会低于 0 ，即 batteryPercentages[j] = max(0, batteryPercentages[j] - 1)。
      • 移动到下一个设备。
    • 否则，移动到下一个设备而不执行任何测试。

    返回一个整数，表示按顺序执行测试操作后 已测试设备 的数量。

    def carPooling(self, trips: List[List[int]], capacity: int) -> bool:

        for num, from_, to in trips:

            d[to] -= num

class Solution:

    def carPooling(self, trips: List[List[int]], capacity: int) -> bool:

        d = defaultdict(int)

        for num,f,to in trips:

            d[f] += num

            d[to] -= num

        s = 0

        for k in sorted(d):

            s += d[k]

            if s > capacity:

                return False

        return True

    class Solution:

    def corpFlightBookings(self, bookings: List[List[int]], n: int) -> List[int]:

        nums = [0] * n

        for l,r,x in bookings:

            nums[l - 1] += x

            if r < n:

                nums[r] -= x

        return list(accumulate(nums))


class Solution:

    def corpFlightBookings(self, bookings: List[List[int]], n: int) -> List[int]:

        diff = [0] * (n + 2)

        for l,r,x in bookings:

            diff[l] += x

            diff[r + 1] -= x

        s = list(accumulate(diff))

        return s[1:-1]

    class Solution:

    def isZeroArray(self, nums: List[int], queries: List[List[int]]) -> bool:

        diff = [0] * (len(nums) + 1)

        for l,r in queries:

            diff[l] += 1

            diff[r + 1] -= 1

        for x,num_d in zip(nums,accumulate(diff)):

            if x > num_d:

                return False

        return True
